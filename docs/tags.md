# Documentation Tags

**Tags:** [#documentation](#documentation) [#navigation](#navigation)

This index connects related project documents through a shared set of tags. Every Markdown document should place its linked tags directly below its top-level heading.

When adding a new tag:

1. Add the linked tag to the document using `[#tag-name](tags.md#tag-name)`.
2. Add a matching section to this index.
3. List every document that uses the tag.
4. Use lowercase words separated by hyphens.

Root-level documents use `docs/tags.md#tag-name`; documents inside `docs/` use `tags.md#tag-name`.
